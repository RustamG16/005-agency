# Section 10 — Inquiry CTA

Status: **required page section; UI mockup not generated or approved yet**

This file exists so the assembled sequence contains all sections and a new chat does not mistake Section 09 for the end of the page.

## Purpose

Turn the completed story and proof into one confident invitation to start a conversation or project.

## Required composition

- Same warm ivory, near-black, and deep-burgundy editorial system as every previous section.
- Typography-led rather than another cinematic scene.
- One strong closing statement, one short supporting sentence, and one primary project CTA.
- Preserve the global navigation/footer conventions of the existing Convenium site.
- Optional compact appearance of Convenium's own red/black website pet is allowed only if it supports the CTA and does not restart the business-companion metaphor.
- No new founder or companion media is required.

## Motion contract

- Normal scroll; no pin, scrub, horizontal sequence, or long reveal.
- One short functional entrance may animate the headline, rule, and CTA with transforms and `autoAlpha`.
- Hover/focus/tap feedback must be fast, subtle, and accessible.
- Reduced motion shows the complete CTA immediately.

## Stop condition

Before implementation, generate or design one full desktop UI mockup and one mobile state, then ask Rustam to lock it. Do not treat this requirement file as visual approval.
