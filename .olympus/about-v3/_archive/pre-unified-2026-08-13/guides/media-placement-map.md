# About V3 media placement map — discussion draft

Status: **placeholders implemented; Rustam/shared section-specific direction approved for prompt production**.

This document maps the visible page slots before prompts are rewritten. It deliberately rejects generic architecture as the default answer. Architecture may appear only when it is real project proof or when a spatial detail is necessary to communicate a specific brief decision.

## Working media balance

- **People and observable decisions — about 55–65%.** Founder portraits, gestures, reviewing, sequencing, choosing, comparing and aligning.
- **Real work and interfaces — about 25–35%.** Cleared recordings, interface behavior, real content artifacts and actual system fragments.
- **Material/abstract transition details — no more than 10–15%.** Paper, type, cursor, grid, crop, shadow, marker or object detail. Never a stream of unrelated architecture.
